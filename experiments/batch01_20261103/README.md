**检查与解释**。G2 的 MLP 已存在，跳过训练。H4 未新增 ST/停牌/涨跌停过滤，保持既有策略；Qlib 中国市场的有效默认涨跌停阈值为 0.095，具体见 checks/H4.json。

gated_attn 为 SDPA 输出与 out_proj 之间的逐头 sigmoid 门，零权重/偏置初始化对应 0.5 门值。fsq_ca_dim 使用整数单位 abs(u-q) 三维输入、零初始化适配器。fsq_grid 的 Stage 1 仍为 128 维，下游潜在因子与相应投影变成 3 维；CA 使用归一化网格坐标量化误差，预测路径不调用 from_grid。该实验同时改变因子数和 CA 几何空间，不能将效果仅归因于坐标形式。
